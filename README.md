# 팡팡 풍선 🎈

손을 화면 속 풍선에 갖다 대면 풍선이 "팡!" 하고 터지는 영아용 놀이 웹앱입니다.
카메라 앞에서 손을 움직이면 MediaPipe Hands가 손 위치를 찾아 풍선을 터뜨리고,
카메라를 쓰지 않을 때는 화면을 터치해서 놀 수 있습니다.

▶ 바로 놀기: https://lahee316-art.github.io/pang-pang-balloon/

## 🔒 개인정보 안내

**카메라 영상은 기기 안에서만 처리되고 저장·전송되지 않습니다.**

- 손 인식은 브라우저 안에서 실행되며, 영상이나 사진을 서버로 보내지 않습니다.
- 녹화·캡처 기능이 없고, 놀이를 마치거나 카메라를 끄면 카메라가 바로 꺼집니다.
- 인터넷으로 내려받는 것은 손 인식 프로그램 파일(MediaPipe)과 글꼴뿐입니다.

## 사용 방법

1. 위 주소를 휴대폰·태블릿·노트북 브라우저(Chrome, Safari 등)에서 엽니다.
2. 시작 버튼을 누르고, 카메라 허용 창이 뜨면 **허용**을 누릅니다.
3. 아이가 화면 앞에서 손을 흔들어 풍선을 터뜨립니다.

> 카메라는 https 주소에서만 켜집니다. 카메라를 허용하지 않아도 화면 터치로 놀 수 있어요.
